# Project Summary

**Marcos Pantoja — CSC199, California State University, Sacramento**

This project conducted a systematic security audit of the Python Package Index (PyPI) ecosystem, targeting command injection vulnerabilities in open-source Python packages. Using a custom-built static analysis scanner and a four-phase methodology — reconnaissance, static analysis, dynamic testing, and exploit development — approximately 185 packages were reviewed, resulting in one confirmed original finding: a high-severity command injection vulnerability (CVSS 7.8) in Luigi's SGE workflow module, where an attacker-controlled CLI parameter flows directly into a `subprocess.check_output(shell=True)` call with no sanitization. The vulnerability was fully documented with a working proof-of-concept exploit, CVSS scoring, and a detailed audit report, and responsibly disclosed to Spotify through three channels — HackerOne, a GitHub issue, and direct email — with no response received. An independent re-discovery of a previously patched vulnerability in the Watchdog package validated the methodology by demonstrating that the same systematic process surfaces real, confirmed issues. Beyond the individual findings, this project reinforced a broader truth about supply chain security: the combination of `shell=True` and unescaped string formatting is a persistent, systematic anti-pattern in automation and workflow tools, and the impact of a single vulnerable configuration point scales with every downstream user who trusts that tool. Working through real codebases — tracing data flows, confirming exploitation, and navigating the disclosure process — gave me a concrete understanding of how vulnerability research works in practice, and cemented my direction toward a career in offensive security.
